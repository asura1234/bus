How these are counted

Delivery is whether Bus handed the message off. Reply capture is separate and only for messages that expect a reply. Settled delivery, excluding still-open attempts, remains delivered ÷ (delivered + failed). The headline Delivery % is delivered ÷ attempted, so a still-open message lowers it.
